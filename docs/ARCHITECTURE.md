# Архитектура AI-тренера

## Компоненты

1. **Telegram Bot / Cloudflare Worker** — принимает команды и проверяет Telegram ID владельца.
2. **Доменный слой** — расписание, ограничения по травмам и расчёты без участия LLM.
3. **Cloudflare D1** — история тренировок, питания, веса, замеров и синхронизаций.
4. **Cloudflare R2** — исходные Word-файлы, изображения и резервные копии после включения облака.
5. **Локальный агент Windows** — импорт Word, локальная копия и резервирование.
6. **Gemini** — разбор свободного текста и составление программ после применения правил безопасности.

Персональный JSON-экспорт формируется Worker напрямую из D1 только после отдельного подтверждения владельца. Он не заменяет зашифрованную резервную копию: JSON нужен для чтения и переносимости, резервная SQL-копия — для полного восстановления системы.

Команда `/status` детерминированно сводит свежесть и покрытие ключевых данных: цель, тренировки, питание, вес, объёмы, чекины сна и готовности, травмы, добавки, анализы и внешние подключения. Она не вызывает Gemini и не делает медицинских выводов; её задача — показать, каких фактов не хватает наставнику.

## Поток тренировки

`Telegram -> сегодня -> предтренировочный чекин -> правила безопасности -> расписание -> ограничения -> история -> Gemini -> план -> Telegram`

Для запроса на завтра чекин не выполняется, потому что фактическое состояние будет известно только в день тренировки. Если план был составлен заранее, перед его выдачей по запросу на сегодня всё равно требуется актуальный чекин.

После выполнения пользователь отправляет фактические подходы. Бот показывает краткое подтверждение и сохраняет подтверждённую сессию в D1.

Голосовой отчёт до двух минут проходит тем же подтверждаемым staging-процессом, но Gemini за один запрос сразу формирует структуру отчёта из аудио и текущего плана. Исходное аудио постоянно не хранится, повторный `file_unique_id` не отправляется модели снова.

Оба чекина разбираются детерминированно, без Gemini: предтренировочный хранит сон, качество сна, энергию, текущую боль и красные флаги; послетренировочный — субъективную тяжесть, RIR, боль и общее самочувствие.

## Безопасность

- Доступ только Telegram ID владельца.
- Травмы и запрещённые нагрузки фильтруются кодом до и после ответа модели.
- Модель не ставит диагнозы и не отменяет назначения врача.
- При резком ухудшении самочувствия сценарий требует остановить тренировку и обратиться за медицинской помощью.
- Секреты находятся в Cloudflare Secrets и локальном `.env`, исключённом из Git.

## FatSecret

Направление данных: `FatSecret -> AI-тренер`. Публичные условия FatSecret ограничивают постоянное хранение большинства данных API сроком менее 24 часов. Постоянный архив включается только при письменном разрешении FatSecret либо через официальный пользовательский экспорт CSV/PDF. До этого доступен аварийный ввод итогового КБЖУ одним скриншотом.

## Будущие источники здоровья

Интеграции будут адаптерами к единому формату: Apple Health export/Shortcuts, Garmin, Xiaomi и другие. Миграция `0034` и слой нормализации уже принимают сон и его стадии, пульс покоя, HRV, шаги, активную энергию, сатурацию, дыхание, температуру и оценки сна/готовности. Единицы приводятся к минутам, bpm, ms, количеству, kcal, процентам и °C; обязательны источник, время с часовым поясом, качество и ключ дедупликации. Отсутствие браслета не создаёт фиктивных записей и не влияет на первый релиз.
