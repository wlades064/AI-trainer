# Архитектура AI-тренера

## Компоненты

1. **Telegram Bot / Cloudflare Worker** — принимает команды и проверяет Telegram ID владельца.
2. **Доменный слой** — расписание, ограничения по травмам и расчёты без участия LLM.
3. **Cloudflare D1** — история тренировок, питания, веса, замеров и синхронизаций.
4. **Cloudflare R2** — исходные Word-файлы, изображения и резервные копии после включения облака.
5. **Локальный агент Windows** — импорт Word, локальная копия и резервирование.
6. **Gemini** — разбор свободного текста и составление программ после применения правил безопасности.

## Поток тренировки

`Telegram -> сегодня/завтра -> расписание -> ограничения -> история -> Gemini -> план -> Telegram`

После выполнения пользователь отправляет фактические подходы. Бот показывает краткое подтверждение и сохраняет подтверждённую сессию в D1.

## Безопасность

- Доступ только Telegram ID владельца.
- Травмы и запрещённые нагрузки фильтруются кодом до и после ответа модели.
- Модель не ставит диагнозы и не отменяет назначения врача.
- При резком ухудшении самочувствия сценарий требует остановить тренировку и обратиться за медицинской помощью.
- Секреты находятся в Cloudflare Secrets и локальном `.env`, исключённом из Git.

## FatSecret

Направление данных: `FatSecret -> AI-тренер`. Публичные условия FatSecret ограничивают постоянное хранение большинства данных API сроком менее 24 часов. Постоянный архив включается только при письменном разрешении FatSecret либо через официальный пользовательский экспорт CSV/PDF. До этого доступен аварийный ввод итогового КБЖУ одним скриншотом.

## Будущие источники здоровья

Интеграции будут адаптерами к единому формату: Apple Health export/Shortcuts, Garmin, Xiaomi и другие. Отсутствие браслета не влияет на первый релиз.
