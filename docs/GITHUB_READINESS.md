# Подготовка GitHub-репозитория

Проект пока не опубликован и не имеет удалённого Git-репозитория.

## Рекомендуемый режим

Репозиторий должен быть приватным, потому что seed-файлы содержат персональную историю тренировок и ограничения по здоровью. Публичную версию можно делать только после отделения и удаления персональных seed-файлов из истории Git.

## Не включать в Git

- `.dev.vars`, `.env` и их локальные варианты;
- ключи Telegram, Gemini и Cloudflare;
- локальные SQLite/D1-файлы;
- содержимое `data/` и `backups/`;
- оригинальные документы, скриншоты и будущие медицинские файлы;
- приватные ключи и сертификаты.

## Перед первой публикацией

1. Повторить автоматическую проверку файлов на ключи и токены.
2. Проверить список файлов первого коммита.
3. Создать приватный репозиторий.
4. Добавить удалённый `origin` и отправить ветку только после подтверждения владельца.
5. Не переносить секреты в GitHub Actions; использовать GitHub Secrets только при появлении CI/CD.

Текущие рабочие секреты находятся в игнорируемом `apps/bot-worker/.dev.vars` и в секретах Cloudflare Worker.
