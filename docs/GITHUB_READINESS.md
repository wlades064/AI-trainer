# Подготовка GitHub-репозитория

Проект опубликован в приватном репозитории: https://github.com/wlades064/AI-trainer. Локальный `origin` использует HTTPS, ветка `master` отслеживает `origin/master`.

## Рекомендуемый режим

Репозиторий должен быть приватным, потому что seed-файлы содержат персональную историю тренировок и ограничения по здоровью. Публичную версию можно делать только после отделения и удаления персональных seed-файлов из истории Git.

## Не включать в Git

- `.dev.vars`, `.env` и их локальные варианты;
- ключи Telegram, Gemini и Cloudflare;
- локальные SQLite/D1-файлы;
- содержимое `data/` и `backups/`;
- оригинальные документы, скриншоты и будущие медицинские файлы;
- приватные ключи и сертификаты.

## Выполненная проверка

1. Просканированы текущие файлы и 26 коммитов на ключи Telegram, Gemini, GitHub и приватные ключи — совпадений нет.
2. Подтверждено исключение `.dev.vars`, локальных баз, `data/`, `backups/` и DPAPI-ключа.
3. Репозиторий создан с видимостью `PRIVATE`.
4. `origin` добавлен, история ветки отправлена.
5. GitHub Actions пока не подключены; при появлении CI/CD секреты должны храниться только в GitHub Secrets.

Текущие рабочие секреты находятся в игнорируемом `apps/bot-worker/.dev.vars` и в секретах Cloudflare Worker.
