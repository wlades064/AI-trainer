# Состояние развёртывания

Обновлено: 2026-08-25.

## Работает

- Cloudflare Worker: `https://ai-trainer-bot.wlades64-ai.workers.dev`;
- публичный `GET /health` возвращает `200` и `{"status":"ok"}`;
- Telegram webhook зарегистрирован с секретным заголовком;
- доступ разрешён только Telegram ID владельца;
- тестовые `/today` и `/tomorrow` прошли весь путь Telegram webhook -> Worker -> Gemini -> D1 -> Telegram;
- в облачной D1 создан один профиль и три правила расписания;
- применены миграции `0001_initial.sql` — `0010_telegram_update_deduplication.sql`;
- импортированы 76 выполненных тренировок, включая 75 тренировок из Word и тренировку за 2026-08-24 из Telegram;
- в каталоге 94 упражнения, а ограничения по коленям и голеностопам участвуют в отборе упражнений;
- Gemini формирует структурированный план только из разрешённых кандидатов, результат сохраняется в D1 и повторно используется без нового расхода токенов;
- рабочая модель — `gemini-3.6-flash` через `generateContent`;
- первая успешная генерация создала тренировку спины на 2026-08-26 из 6 упражнений и была отправлена в Telegram;
- одинаковый Telegram `update_id` обрабатывается один раз; сбойный запрос можно безопасно повторить;
- тренировки отправляются только по явному запросу пользователя; cron не формирует и не отправляет тренировки;
- cron: ежедневный сбор в 23:50 по Самаре и понедельник 09:00 по Самаре.

## Gemini

Gemini вызывается из Cloudflare Worker и работает. Для структурированного ответа используются `responseMimeType: application/json` и JSON Schema. Клиент ограничивает длительность запроса 25 секундами, а при сбое бот возвращает безопасный резерв на основе истории.

Модель `gemini-2.5-flash` недоступна новым пользователям этого API-проекта; API Google потребовал перейти на `gemini-3.6-flash`. Эта модель успешно проверена в рабочем Worker. Gemma остаётся только будущим резервом, если возможностей Gemini станет недостаточно.

Контрольная генерация использовала 1317 входных и 580 выходных токенов. Расход записан в `ai_usage`. Перед последним развёртыванием прошли 12 автоматических тестов и строгая проверка TypeScript.

Следующий этап — сценарий фиксации фактически выполненной тренировки через Telegram с подтверждением подходов, веса, повторений, боли и самочувствия.
