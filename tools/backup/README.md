# Локальные зашифрованные копии

`backup-crypto.mjs` шифрует подготовленный экспорт базы алгоритмом AES-256-GCM. Ключ выводится из парольной фразы через scrypt. Изменение файла, неверный пароль и неполная копия обнаруживаются при расшифровке.

Пароль не передаётся аргументом командной строки и не хранится в проекте. Скрипт читает его только из переменной процесса `AI_TRAINER_BACKUP_PASSPHRASE`. Пароль должен содержать не менее 16 символов.

Существующий выходной файл никогда не перезаписывается. Расширение `.aitbackup` исключено из Git.

## Первый запуск на Windows

Ключ можно ввести вручную или безопасно сгенерировать. Он сохраняется через Windows DPAPI: прочитать его сможет только текущая учётная запись Windows на этом компьютере.

```powershell
.\tools\backup\initialize-backup-secret.ps1
# либо локальный случайный ключ без показа на экране
.\tools\backup\initialize-backup-secret.ps1 -Generate
```

Случайный DPAPI-ключ подходит для автоматической копии на этом ПК, но после переустановки Windows не восстановится. Для переносимого аварийного восстановления следует задать собственную длинную парольную фразу и отдельно хранить её в менеджере паролей.

## Создание и проверка

```powershell
.\tools\backup\backup-d1.ps1
.\tools\backup\verify-backup.ps1 -BackupPath .\backups\ai-trainer-ГГГГММДД-ЧЧММСС.aitbackup
```

`backup-d1.ps1` выгружает всю удалённую D1, проверяет наличие схемы, шифрует экспорт и удаляет открытый SQL из временного каталога. Рядом сохраняется SHA-256. Существующие копии не перезаписываются.

`verify-backup.ps1` проверяет SHA-256, расшифровывает копию во временный каталог и выполняет весь дамп в изолированной SQLite, совместимой с D1. Затем он проверяет число таблиц, пользователей, подтверждённых тренировок и все внешние ключи. Рядом с архивом сохраняется квитанция `.verified.json`. Рабочую облачную базу этот сценарий не изменяет. Прямое автоматическое восстановление в production намеренно отсутствует.

## Ежедневный цикл

```powershell
.\tools\backup\run-backup-cycle.ps1
.\tools\backup\install-backup-task.ps1 -DailyAt 03:30
```

Цикл создаёт архив, обязательно проверяет восстановление и только после успеха применяет ротацию. Хранятся последние 30 проверенных архивов; непроверенные файлы автоматически не удаляются. Результат последнего запуска находится в `backups\last-run.json`.

Задание Windows запускается только в текущей учётной записи пользователя. Если в 03:30 компьютер выключен или спит, `StartWhenAvailable` запускает копирование при первой возможности после входа. Одновременно два цикла не запускаются.
