# Локальные зашифрованные копии

`backup-crypto.mjs` шифрует подготовленный экспорт базы алгоритмом AES-256-GCM. Ключ выводится из парольной фразы через scrypt. Изменение файла, неверный пароль и неполная копия обнаруживаются при расшифровке.

Пароль не передаётся аргументом командной строки и не хранится в проекте. Скрипт читает его только из переменной процесса `AI_TRAINER_BACKUP_PASSPHRASE`. Пароль должен содержать не менее 16 символов.

Существующий выходной файл никогда не перезаписывается. Расширение `.aitbackup` исключено из Git.

Реальную автоматическую выгрузку D1 и расписание нужно подключать только после выбора способа безопасного хранения парольной фразы и проверки восстановления на отдельной копии.
