# Импорт пользовательского экспорта FatSecret

FatSecret на iOS позволяет в дневнике выбрать период, тип отчёта и формат CSV. Официальная инструкция: https://www.fatsecret.com/fatsecret-app-help/reports-page/use-export-or-print-function. Этот импорт использует файл, который владелец экспортировал сам, а не Platform API.

```powershell
node .\tools\fatsecret-import\import-fatsecret.mjs .\FoodDiary.csv .\data\fatsecret-draft.sql
```

Импортёр распознаёт запятую и точку с запятой, английские и основные русские заголовки, суммирует записи по календарному дню и игнорирует строки `Total/Итого`, чтобы не удвоить КБЖУ. В SQL попадают только дата и общий КБЖУ; названия продуктов и приёмы пищи не сохраняются.

Результат — проверяемый SQL-черновик. Он не применяется автоматически: сначала нужно сравнить число дней и несколько итогов с FatSecret. Существующий файл не перезаписывается.
