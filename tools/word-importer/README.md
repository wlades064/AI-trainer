# Импорт тренировок из Word

Импорт состоит из двух стадий:

1. `import_docx.py` извлекает содержимое `.docx` в JSON со статусом `needs_review`;
2. `parse_history.py` делит журнал на датированные тренировки, сохраняя исходные строки;
3. `build_staging_sql.py` создаёт идемпотентный SQL для таблицы `imported_documents`;
4. будущий валидатор сопоставит строки с упражнениями и попросит подтверждение перед переносом в основную историю.

Пример:

```powershell
python import_docx.py "D:\путь\тренировки.docx"
```

Исходный Word-файл не изменяется. SHA-256 защищает от повторного импорта одного и того же файла.
